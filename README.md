# Upwork Freelancer Playbook

A Claude skill and reference for Upwork freelancers: job vetting, proposals, profile, portfolio items, Project Catalog listings, consultations and boost messages, within Upwork's rules and limits.

- [`SKILL.md`](SKILL.md) is the full playbook (hard rules, field limits, workflows, how clients evaluate freelancers).
- Section 7 is a template: fill in your own positioning and proof.
- Field limits marked "third-party" can change, so always trust the live form counter.
